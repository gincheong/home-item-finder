# 🏠 집안 물건 찾기

**"이거 어디 뒀더라?"** 를 다시는 묻지 않도록.

집 구조를 캔버스에 직접 그리고, 가구마다 물건을 기록해두면 검색 한 번으로 위치를 바로 찾을 수 있는 웹 앱입니다.

---

## 이런 분께 추천해요

- 서랍이 많아서 뭐가 어디 있는지 자주 까먹는 분
- 이사 후 정리했는데 물건 위치가 머릿속에 없는 분
- 가족끼리 물건 위치를 공유하고 싶은 분

---

## 주요 기능

### 집 구조 그리기
캔버스를 드래그해서 방을 직접 그릴 수 있어요. 방 이름을 바꾸고, 크기와 위치를 자유롭게 조절할 수 있어요. 필요 없는 방은 우클릭 메뉴나 사이드바에서 바로 삭제할 수 있어요.

### 가구 배치
서랍장, 옷장, 선반, 커스텀 가구를 방 안에 놓고 원하는 위치로 옮길 수 있어요. 가구는 방 경계 밖으로 벗어나지 않고, 방을 옮기면 안에 있는 가구도 함께 따라 이동해요. 가구를 삭제하면 안에 기록된 서랍과 물건도 함께 지워져요.

### 물건 등록
가구 안에 서랍(칸)을 만들고, 각 서랍에 물건을 기록해요. 이름뿐만 아니라 메모와 태그도 달 수 있어요.

### 빠른 검색
물건 이름, 메모, 태그로 검색하면 **몇 번 방 → 어떤 가구 → 몇 번 서랍** 까지 바로 알려줘요.

### 데이터 백업
JSON 파일로 내보내고 가져올 수 있어요. 브라우저를 닫아도 데이터는 자동으로 저장돼요.
